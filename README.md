# Savor - Statamic Starter Kit

Savor is a restaurant starter kit for seasonal kitchens, chef-led dining rooms, and table-booking brands. It is built for Statamic 5 with a wine-and-linen palette, named chefs, and Control Panel content management.

The kit ships four home variants, menu listings, reservations, events, shop pages, blog and podcast layouts, and membership content so a restaurant can publish its menu and take booking inquiries from one site.

- **Schedule**
- **Events**:

- **Experiences**:

- **Shop**:

## Collections

Organize your content with built-in collections (handles in parentheses):

- **Pages**: Site structure and hierarchical content.
- **Menus** (`classes`): Dishes, courses, and seasonal plates.
- **Events**: Dinners, tastings, and special nights.
- **Experiences** (`retreats`): Chef tables and hosted dining.
- **Products**: Retail items for the shop.
- **Blogs**: Kitchen stories and seasonal notes.
- **Podcast** and **Podcast episode**: Audio series and individual episodes.
- **Teams**: Chefs and front-of-house staff.
- **Testimonials**: Guest reviews.
- **FAQs**: Reservations and dining questions.
- **Comments**: Blog and menu comments.

## Features of Savor

- **Restaurant menus**: Listing variants, dish detail, and a reservation form.
- **Rich page builder**: Flexible sets for heroes, content blocks, galleries, and more.
- **Shop pages**: Catalog, cart, and wishlist layouts for pantry and merch.

- **Global settings**: Header, footer, social share, and 404 copy from the Control Panel.
- **Responsive layout**: Desktop, tablet, and mobile.

## Installation

Follow the [Starter Kit installation instructions](https://statamic.dev/starter-kits/installing-a-starter-kit) to get started with Savor.
Make sure you're running **Statamic 5.x** for compatibility.

### Installing into an existing site

```bash
php please starter-kit:install webbycrown/savor-statamic-theme
```

### Installing via the Statamic CLI Tool

If you have the [Statamic CLI Tool](https://github.com/statamic/cli) installed, create a new Statamic installation with Savor in one command:

```bash
statamic new my-site webbycrown/savor-statamic-theme
```
